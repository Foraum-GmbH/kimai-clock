# AGENTS.md

KimaiClock — native macOS SwiftUI menu bar app (Kimai 2 time tracking). No SwiftPM, no third-party dependencies. Unit tests run via the `KimaiClockTests` target/scheme.

## Verify changes

```bash
xcodebuild -project KimaiClock.xcodeproj -scheme KimaiClock -configuration Debug build
xcodebuild -project KimaiClock.xcodeproj -scheme KimaiClock -configuration Debug test
swiftlint --strict          # same command CI runs, from repo root
```

- Run unit tests via `xcodebuild -project KimaiClock.xcodeproj -scheme KimaiClock test` or `xcodebuild -project KimaiClock.xcodeproj -scheme KimaiClockTests test`.
- CI runs SwiftLint (`.github/workflows/linting.yaml`).
- Requires full Xcode, not just CommandLineTools (`xcode-select` must point at an Xcode.app). Xcode 26 toolchain is what CI uses (`macos-26`, `latest-stable`).
- `.swiftlint.yml` lives in `KimaiClock/`, so `KimaiClock/**` uses the project rules (strict, opt-in `sorted_imports`/`implicit_return`) while `KimaiWidget/**` is linted with SwiftLint defaults.

## Project layout

- `KimaiClock/` — app target, source of truth. `KimaiWidget/` — widget extension. `KimaiClockTests/` — unit test target. `docs/` is an unrelated GitHub Pages site.
- Targets use Xcode 16 **synchronized folders**: a new `.swift` file dropped into `KimaiClock/`, `KimaiWidget/`, or `KimaiClockTests/` joins that target automatically. Do not hand-edit `project.pbxproj` to add files.
- `Info.plist` and `.swiftlint.yml` are membership exceptions (not compiled). `KimaiClock/Manager/WidgetSync.swift` and `KimaiClock/Extensions/Color.swift` are wired into the **widget** target too via exception sets — treat edits there as widget-breaking (WidgetSync references the app-side `Activity` type while the widget declares its own `struct Activity`) and always build both targets.

## Architecture

- `App.swift` declares only an **empty `Settings` scene**. Every setting lives inside the popover (`Views/PopupView.swift`). Don't add a settings window without asking.
- `AppDelegate.swift` is the composition root: it creates all managers, builds the `NSStatusItem`, injects them as `@EnvironmentObject`s into `PopupView`, and owns the URL-scheme handlers (`kimai-clock://startLast|pause|stop`).
- Managers are `@MainActor ObservableObject`s using Combine. `ApiManager` is the only place that talks to the Kimai REST API (`/api/timesheets`, `/api/activities`, `/api/projects`, `/api/version`); it authenticates with a bearer token from `UserDefaults`.
- Persistence is plain `@AppStorage`/`UserDefaults` — the API token is **not** in the Keychain. Shared widget state lives in the app group suite `group.de.foraum.KimaiClock` via `WidgetSync`.
- `TimerModel` and `ApiManager.activeActivity` call `WidgetCenter.reloadAllTimelines()` from `didSet` — i.e. on every 1s tick. Avoid adding more timeline reloads.
- On quit and on power-off the app **stops the running timesheet on the server** (`stopKimaiTask`). Don't change this casually.

## Language / build settings that dictate style

- Swift 6 language mode. The app and test targets set `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` while the **widget target does not** — widget code must annotate `@MainActor` explicitly when interacting with UI or main-actor state.
- `SWIFT_UPCOMING_FEATURE_MEMBER_IMPORT_VISIBILITY` is why every Combine-using file starts with `internal import Combine`. Follow that; plain `import Combine` will not match the codebase.
- Swift is indented with **4 spaces** (no tabs), as set in `.editorconfig`. Plists and entitlements use tabs.
- Localized strings use `NSLocalizedString("snake_case_key", comment: "")`. `KimaiClock/Localizable.xcstrings` is generated by the build (`SWIFT_EMIT_LOC_STRINGS`) and has `en` + `de`; add new keys for both languages.

## Sandbox & entitlements

- App is sandboxed with hardened runtime; outbound network only. `NSAllowsArbitraryLoads` in `Info.plist` is required for self-hosted plain-HTTP Kimai servers — don't remove it.
- `LSUIElement` is set: no dock icon, no main window. `AppDelegate` terminates itself if a second instance is running, so kill the installed copy before debugging from Xcode.

## Release

- Releases are tag-driven: push `vX.Y.Z` (strict semver, must be greater than the latest release) and CI archives, signs, notarizes, publishes the DMG, then commits the version/build bump back to `main` and updates the Homebrew tap.
- **Do not** edit `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` in `project.pbxproj` or add `CHANGELOG.md` entries — CI/maintainer owns both.
- Work on a feature branch and open a PR to `main`; the template asks for a linked issue and your Xcode/macOS/Kimai server versions. `.github/CODEOWNERS` requires `@undeaDD` review.
- A TruffleHog pre-commit hook scans for secrets (`pre-commit install`). Never commit real Kimai tokens or `.env` files.
- `AGENTS.md` is the single source of truth for all AI agents. Do not introduce tool-specific instruction files or artifacts; keep documentation generic and open for any AI assistant.
